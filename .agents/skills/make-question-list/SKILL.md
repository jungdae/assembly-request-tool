# 문항목록 만들기

## 1. 언제 쓰는지

- `원문/*.pdf` 자료요구서를 읽어 `data/문항목록.csv`를 만드는 `split.py`가 필요할 때 쓴다.
- 사용자가 `문항목록.csv`를 교체했거나, 기존 `split.py` 출력과 현재 `data/문항목록.csv`가 다르다고 말하면 현재 CSV를 정답 예시로 삼아 `split.py`를 만든다.
- 이 스킬은 문항 분해까지만 다룬다. 답변 작성, 배분 확정, 결재, 국회 제출 기능은 만들지 않는다.

## 2. 먼저 확인할 자료

1. `CONTEXT.md`, `PROGRESS.md`, `00_문제정의/problem.md`, `00_문제정의/design.md`를 읽어 범위와 금지사항을 확인한다.
2. `처리지침.md` 제2장 접수를 읽고 문항 분해 규칙을 확인한다.
3. `data/문항목록.csv`가 있으면 반드시 먼저 읽는다. 이 파일의 열, 비고 표기, 세부항목 연결 방식이 이번 작업의 기준이다.
4. 기존 `split.py`가 있으면 참고하되, 현재 `data/문항목록.csv`와 다르면 CSV 형식을 우선한다.

## 3. split.py 작성 기준

- 폴더 맨 위에 `split.py` 하나만 만든다. PDF 원문과 `data/`의 기존 근거 CSV는 고치지 않는다.
- PDF 읽기는 `pypdf`만 쓴다. 먼저 `pypdf` 설치 여부를 확인하고, 없으면 `pip install pypdf` 명령을 사용자에게 보여 준 뒤 허락을 받아 설치한다.
- 출력 CSV 기본 위치는 `data/문항목록.csv`이고 인코딩은 `utf-8-sig`로 한다.
- 기본 열은 현재 `data/문항목록.csv`와 같게 한다. 현재 기준 열은 `파일명 | 위원회 | 의원 | 제출기한 | 문항번호 | 요구내용 | 세부항목 | 비고`이다.
- 첫 줄 `○○위원회 ○○ 의원실 자료요구서`에서 위원회와 의원을 뽑는다.
- `수신: ... 제출기한: 2026. 10. 12.(월) 18:00까지` 줄에서 날짜를 `YYYY-MM-DD`로 바꾼다.
- `수신:`, `담당 보좌관:`, `끝.` 줄은 문항에 넣지 않는다. 이름, 연락처는 저장하지 않는다.
- 줄 맨 앞이 `숫자.`이면 새 문항이다.
- `가.`, `나.` 줄은 앞 문항의 세부항목이다.
- `※` 줄은 앞 문항의 비고이다.
- 그 밖의 줄은 바로 앞 항목에 잇는다.

현재 교체된 `data/문항목록.csv` 기준의 세부 출력 형식은 다음과 같다.

- 세부항목은 `가. 연도별 건수 / 나. 세부 내역(엑셀 파일로 제출)`처럼 ` / `로 잇는다.
- 비고는 `※` 기호를 빼고 `개인정보는 제외하고 제출할 것`처럼 내용만 쓴다.
- 위 두 형식이 현재 CSV와 다르면 현재 CSV에 있는 형식을 우선한다.

## 4. 검증 순서

1. `split.py`를 실행해 문항목록을 만든다. 기존 `data/문항목록.csv`를 정답으로 비교해야 하면 임시 출력 경로 옵션을 만들거나 임시 파일에 먼저 써서 비교한다.
2. 파일명에 들어 있는 `25문항`, `34문항` 같은 숫자와 뽑은 문항 수, 마지막 번호, 번호 연속 여부를 비교한다.
3. 현재 기준 CSV가 있으면 새 출력과 행 수, 열 이름, 파일명·문항번호별 값이 같은지 비교한다.
4. 세부항목과 비고가 모두 있는 문항 3개를 골라 원문 PDF 추출 줄과 CSV 분해 결과를 나란히 보여 준다.
5. 일치가 `X`이거나 기준 CSV와 다르면 원인을 찾아 `split.py`를 고친 뒤 다시 실행한다.

## 5. 끝나는 조건

- `split.py`가 폴더 맨 위에 있다.
- `data/문항목록.csv`가 `utf-8-sig`로 생성된다.
- 파일별 문항 수, 마지막 번호, 번호 연속 여부가 모두 맞다.
- 현재 기준 `data/문항목록.csv`가 있었던 경우, 교체된 문항목록과 같은 형식과 값이 나온다.
- `수신:`, `담당 보좌관:`, 이름, 연락처, `끝.`이 출력 CSV에 들어가지 않는다.

## 6. 하지 말 것

- `원문/*.pdf`를 수정하지 않는다.
- 과거 접수대장, 검증용 접수대장, 시험 문항, 조직도, 배분기준표, 부서 회신 샘플은 수정하지 않는다.
- `99_완성본_잠금` 폴더는 열거나 풀거나 참고하지 않는다.
- 문항 분해 결과에 없는 개인정보, 연락처, 담당자 이름을 새로 저장하지 않는다.
- 문항 분해 과정에서 조직도 밖 부서명이나 답변 내용을 만들지 않는다.
